# Fix Summary

This artifact summarizes the fixes applied to resolve the lingering UI issues, the GIF positioning issue, and the "Daily End -> Hello World" progression bug.

## 1. "日常エンド→hello world" の原因と修正
**原因 (Cause):**
過去の開発段階で、魔王戦後の「日常エンド (normal_daily)」と「シャットダウンエンド (bad_shutdown)」へ分岐するための研究室での会話イベントブロック（約200行）がまるごとコメントアウト（無効化）されていました。
そのため、条件（魔王を倒す・キル数1~2）を満たして日常エンドウートに入っても、エンディング処理（`ending('normal_daily')`）が呼ばれず、ゲームは戦闘が継続していると誤認して進行してしまっていました。
結果として `proceedToNextArea` が呼ばれ、最終ボスである「博士（Boss 4）」との戦闘が開始されてしまい、博士を倒したことで強制的に `END_ORPHAN`（Hello World）になってしまう、というのが「日常エンドに行こうとするとHello Worldになる」原因でした。

**修正内容 (Fix):**
コメントアウトされていた研究室での会話イベント（日常エンド用とシャットダウンエンド用）を復活させ、分岐条件（`DP < 100` と `DP >= 100`）の中に正しく組み込みました。これにより、日常ルートの条件を満たせば、正しく研究所の背景で会話が発生し、「日常エンド」へと遷移するようになりました。シャットダウンエンド（DP100以上で魔王を殺したとき）のイベントと4つの選択肢も正常に動作します。

## 2. 研究所背景でのバトルレーン・UI・ボスの攻撃（犬猫スター）が残る問題
**原因 (Cause):**
「自由の身エンド (hidden_freedom)」や、復活させた「日常エンド」などのイベントシーンは、シーン遷移（EndingSceneへの移動）を行う**前**に、BossScene内で背景を研究所（`bg_lab`）に切り替えて会話を行っていました。しかし、戦闘モードからイベントモードへの切り替え時に、ボスのHPバーやバトルレーン（`laneGraphics`）、そして犬猫の攻撃判定やグラフィックなどを非表示・停止にする処理が含まれていませんでした。

**修正内容 (Fix):**
研究所背景への切り替え（フェードアウト〜フェードインの間）に、画面上に存在するすべての戦闘UI、バトルレーン、ボスキャラ、犬猫キャラ、弾幕（EnemyBullets / PlayerBullets）を完全に非表示・消去する一斉クリーンアップ処理を追加しました。
これにより、自由の身エンド、日常エンド、シャットダウンエンドなどの会話シーンで、不要なUIや犬猫スターが残ることはなくなりました。

## 3. 真の魔王のGIF画像が左上に寄ってしまう問題
**原因 (Cause):**
PhaserのDOMエレメント機能を使ってGIFを表示する際、単純な `div` に `background-image` を設定する方法では、フルスクリーン時やブラウザのウィンドウサイズ変更時に、基準点やスケーリングが正しく追従できず、左上に寄って見切れてしまう現象が起きていました。

**修正内容 (Fix):**
DOMエレメントを `div` ではなく標準の `img` タグとして生成し、CSSの `object-fit: contain` プロパティを適用する方式に修正しました。
これにより、コンテナ（ゲーム画面）のサイズがフルスクリーンなどで変化しても、アスペクト比を維持したまま常に中央に最大化表示されるようになります。
